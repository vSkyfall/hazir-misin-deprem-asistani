# hazir-misin-deprem-asistani
Deprem öncesi hazırlık ve afet bilinci için geliştirilen bir PWA projesi.

# Hazır mısın? 🌍

**Hazır mısın?**, kullanıcıların deprem öncesinde hazırlık yapmalarına ve afet bilinci kazanmalarına yardımcı olmak amacıyla geliştirilen bir web uygulaması projesidir.

## 🎯 Projenin Amacı

Deprem öncesi hazırlık sürecini kolaylaştırmak, kullanıcıların temel afet bilgilerine ulaşmasını sağlamak ve kişisel hazırlıklarını daha düzenli hâle getirmek.

## ✨ Planlanan Özellikler

- Deprem hazırlık kontrol listesi
- Acil durum çantası hazırlama rehberi
- Önemli acil durum bilgileri
- Kullanıcı verilerini LocalStorage ile saklama
- Mobil cihazlara uyumlu arayüz
- PWA desteği ve çevrimdışı kullanım

> Proje geliştirme aşamasındadır. Özellikler geliştirme sürecinde değişebilir.

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Progressive Web App (PWA)

Yalova Üniversitesi Meslek Yüksekokulu, Ön-Yüz Yazılım Geliştirme programı kapsamında JavaScript Uygulamaları dersi için geliştirilmektedir.

# Hazır mısın? 🌍 | Earthquake Preparedness Assistant

**Hazır mısın?** is a web application project designed to help users prepare for earthquakes and develop disaster awareness.

## 🎯 Project Purpose

The goal of this project is to simplify earthquake preparedness, provide access to essential disaster information, and help users organize their personal emergency preparations.

## ✨ Planned Features

- Earthquake preparedness checklist
- Emergency kit preparation guide
- Essential emergency information
- Local data storage using LocalStorage
- Responsive design for mobile devices
- Progressive Web App (PWA) support and offline functionality

> This project is currently under development. Features may change throughout the development process.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Progressive Web App (PWA)

## 🎓 About the Project

This project is being developed for the **JavaScript Applications** course in the Front-End Software Development program at Yalova University Vocational School, Türkiye.


##🤖 AI Usage

No assistance from AI tools is used during the development of this project. The project is developed individually using HTML, CSS, and JavaScript.
